Available OAuth SSO rake tasks:
===============================

Run tasks with: bundle exec rake redmine:bless_this_sso:<task> [ENV=VALUE ...]

Setup tasks:
  rake redmine:bless_this_sso:install       - Install plugin (check status)
  rake redmine:bless_this_sso:configure     - Configure OAuth provider
  rake redmine:bless_this_sso:test          - Test configuration
  rake redmine:bless_this_sso:validate_flow - Validate full OAuth flow

Management tasks:
  rake redmine:bless_this_sso:status                         - Show current configuration
  rake redmine:bless_this_sso:enable                         - Enable OAuth SSO
  rake redmine:bless_this_sso:disable                        - Disable OAuth SSO
  rake redmine:bless_this_sso:enable_sso_only                - Enable SSO-only mode
  rake redmine:bless_this_sso:disable_sso_only               - Disable SSO-only mode
  rake redmine:bless_this_sso:enable_match_by_email          - Match users by email
  rake redmine:bless_this_sso:disable_match_by_email         - Do not match by email
  rake redmine:bless_this_sso:enable_case_insensitive_login  - Ignore login casing when matching
  rake redmine:bless_this_sso:disable_case_insensitive_login - Require exact login casing
  rake redmine:bless_this_sso:enable_bypass_twofa            - Skip Redmine MFA activation
  rake redmine:bless_this_sso:disable_bypass_twofa           - Require Redmine MFA activation
  rake redmine:bless_this_sso:enable_pkce                    - Use PKCE code challenge
  rake redmine:bless_this_sso:disable_pkce                   - Do not use PKCE
  rake redmine:bless_this_sso:reset                          - Reset configuration

Discovery shortcuts (used with :configure):
  OAUTH_PROVIDER=google                                                     # Google Workspace defaults
  OAUTH_PROVIDER=microsoft OAUTH_MICROSOFT_TENANT=<tenant>                  # Microsoft Entra ID defaults
  OAUTH_PROVIDER=casdoor   OAUTH_CASDOOR_BASE_URL=https://door.example.com  # Casdoor defaults
  OAUTH_DISCOVERY_URL=https://id.example.com/.well-known/openid-configuration
    (Always include OAUTH_CLIENT_ID and OAUTH_CLIENT_SECRET alongside the above.)

General configuration variables:
  OAUTH_PROVIDER_NAME         - Display name (default: Casdoor SSO)
  OAUTH_CLIENT_ID             - OAuth client ID
  OAUTH_CLIENT_SECRET         - OAuth client secret
  OAUTH_SCOPE                 - OAuth scopes (default: openid email profile)
  OAUTH_REDIRECT_URI          - Callback URL (optional, auto-generated)
  OAUTH_LOGOUT_URL            - Provider logout endpoint
  OAUTH_DEFAULT_GROUPS        - Default group IDs for new users

Discovery tuning and endpoint overrides:
  OAUTH_PROVIDER                          - Discovery preset (google, microsoft, casdoor, custom)
  OAUTH_TENANT / OAUTH_MICROSOFT_TENANT   - Microsoft tenant ID or domain
  OAUTH_BASE_URL / OAUTH_CASDOOR_BASE_URL - Base URL for Casdoor discovery
  OAUTH_DISCOVERY_URL                     - Explicit discovery document URL
  OAUTH_AUTHORIZE_URL                     - Authorization endpoint override
  OAUTH_TOKEN_URL                         - Token endpoint override
  OAUTH_USERINFO_URL                      - User info endpoint override
  OAUTH_EXPECTED_ISSUER                   - Expected `iss` claim for ID tokens
  OAUTH_EXPECTED_CLIENT_ID                - Override expected `aud` (defaults to client ID)
  OAUTH_JWKS_URL                          - JWKS endpoint for RS256 verification

Mapping and provisioning options:
  OAUTH_FIELD_PRESET           - Mapping preset (generic, microsoft, google, casdoor)
  OAUTH_LOGIN_FIELD            - Override login mapping
  OAUTH_EMAIL_FIELD            - Override email mapping
  OAUTH_FIRSTNAME_FIELD        - Override first name mapping
  OAUTH_LASTNAME_FIELD         - Override last name mapping
  OAUTH_AUTO_CREATE            - Auto-create users (1 or 0)
  OAUTH_UPDATE_EXISTING        - Update existing users (1 or 0)
  OAUTH_MATCH_BY_EMAIL         - Match users by email when logins differ (1 or 0)
  OAUTH_CASE_INSENSITIVE_LOGIN - Ignore login casing when matching users (1 or 0)
  OAUTH_BYPASS_TWOFA           - Skip Redmine two-factor activation (1 or 0)
  OAUTH_PKCE                   - Use PKCE code challenge (1 or 0)

Example:
  bundle exec rake redmine:bless_this_sso:configure \
    OAUTH_PROVIDER=microsoft \
    OAUTH_MICROSOFT_TENANT=contoso.onmicrosoft.com \
    OAUTH_CLIENT_ID=your-client-id \
    OAUTH_CLIENT_SECRET=your-client-secret
